# Токовинин — база знаний по видео

Сжатые конспекты видео Миши Токовинина ([@mtokovinin](https://www.youtube.com/@mtokovinin))
плюс пайплайн, который их делает.

Два независимых скила:

| Скил | Что делает | Где работает |
|---|---|---|
| `tokovinin-kb-context` | подтягивает нужную часть базы в контекст, когда в разговоре всплывает «Токовинин» | где угодно — Claude Code, Hermes |
| `tokovinin-video-flow` | пайплайн: транскрипт → флаги → сжатый конспект → лог | только локально (нужны `yt-dlp`, `hermes`, cron) |

---

## Установка: только база знаний (Claude Code)

Один файл, без зависимостей. База тянется по HTTP из этого репозитория:

```bash
curl -fsSL https://raw.githubusercontent.com/idjugostran/tokovinin/main/skill/tokovinin-kb-context/scripts/install.sh | bash
```

Скрипт сначала проверяет, что база читается, потом кладёт `SKILL.md` в
`~/.claude/skills/`. Повторный запуск обновляет скил. В claude.ai (web)
скилс-директории нет — там папка `skill/tokovinin-kb-context/` загружается
через Skills UI.

Перезапусти Claude Code и упомяни Токовинина в любом сообщении — скил
сработает сам.

Удалить:

```bash
rm -rf ~/.claude/skills/tokovinin-kb-context
```

Кроме этой папки установка не трогает ничего: ни конфигов, ни cron, ни
системных пакетов.

## Установка: весь пайплайн (Hermes + cron)

Нужны Homebrew, Python 3 и установленный [Hermes](https://hermes.nousresearch.com).

```bash
curl -fsSL https://raw.githubusercontent.com/idjugostran/tokovinin/main/skill/tokovinin-video-flow/scripts/setup.sh | bash
```

Клонирует проект в `~/Tokovinin`, ставит `yt-dlp`, регистрирует оба скила в
Hermes и заводит cron каждые 3 часа. Идемпотентно. Флаги и подробности — в
шапке самого `setup.sh`.

## Как устроена база

```
kb/
├── index.md          # генерируется: id, название, длительность, главы каждого видео
└── videos/<id>.md    # полный конспект одного видео
```

Читающий скил берёт `index.md` (~10k токенов), выбирает по названиям глав
одно-два нужных видео и догружает только их (медиана ~1.5k токенов). Вся база
целиком — ~124k токенов, поэтому она и разбита: типичный ответ обходится в
~13k вместо 124k.

Сейчас в базе 64 видео. Пополняется по мере запуска пайплайна, не по
расписанию — считать её «всем, что обработано», а не «всем, что есть на
канале».

`index.md` руками не правится, он собирается из `kb/videos/`:

```bash
python3 skill/tokovinin-video-flow/scripts/kb_index.py
```

В конспектах выброшена реклама, вода и дословный пересказ чужих роликов
(правила — `skill/tokovinin-video-flow/references/compression-rules.md`).
Скил цитирует с прямыми ссылками на момент в видео (`youtu.be/<id>?t=514`).
Канал в основном в формате реакции, поэтому позиция Токовинина и позиция
разбираемого ролика в конспектах разведены явно.

`transcripts/` в `.gitignore`: это ~50 МБ сырых автосубтитров, локальный
аудит-след, ничему в репозитории они не нужны.

## Оговорки

- База — производная от публичных автосубтитров YouTube: пересказ тезисов
  своими словами, не транскрипт и не копия видео. Цитаты короткие и со
  ссылкой на источник.
- Проект неофициальный, к Мише Токовинину и его каналу отношения не имеет.
- Флаги (`possible_sponsor_intro`, `possible_other_speakers`) — эвристики с
  ложными срабатываниями в обе стороны. Это сигнал для перепроверки, а не
  истина.
