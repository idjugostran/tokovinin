# Токовинин — база знаний по видео

Вики-конспект видео Миши Токовинина ([@mtokovinin](https://www.youtube.com/@mtokovinin))
в формате wiki-LLM, собранная из полных транскриптов 64 видео канала.

| Скил | Что делает | Где работает | Статус |
|---|---|---|---|
| `tokovinin-kb-context` | подтягивает нужную часть вики в контекст, когда в разговоре всплывает «Токовинин» | где угодно — Claude Code, Hermes | активен |
| `tokovinin-video-flow` | старый пайплайн: транскрипт → флаги → сжатый конспект в `kb/` | только локально (нужны `yt-dlp`, `hermes`, cron) | отключён, писал в формат `kb/`, который заменён вики |

---

## Установка: только база знаний (Claude Code)

```bash
curl -fsSL https://raw.githubusercontent.com/idjugostran/tokovinin/main/skill/tokovinin-kb-context/scripts/install.sh | bash
```

Ставит один файл (`SKILL.md`) в `~/.claude/skills/tokovinin-kb-context/`. Сама
база никогда не скачивается целиком — скил читает нужные страницы вики с
GitHub по HTTPS в момент ответа. Кроме этой папки установка не трогает
ничего: ни конфигов, ни cron, ни системных пакетов.

Идемпотентно — повторный запуск просто перезаписывает `SKILL.md` текущей
версией (так же скил и обновляется).

Удалить:

```bash
rm -rf ~/.claude/skills/tokovinin-kb-context
```

## Пайплайн пополнения (отключён)

`tokovinin-video-flow` (Hermes + cron) собирал старый формат `kb/` —
механически нарезанные автосубтитры, а не тезисы. Он отключён с переходом
на вики 2026-08-15 и `setup.sh` из него ставить не стоит: писать ему уже
некуда, `kb/` удалена. Новые видео в вики добавляются вручную через
`wiki-ingest` (см. `SCHEMA.md`), не по расписанию.

## Как устроена база

С 2026-08-15 база — вики в формате wiki-LLM (тот же формат, что у
zicer-wiki и freelance-wiki), собранная из полных транскриптов, а не из
сырых автосубтитров:

```
wiki/
├── index.md          # генерируется: каталог всех страниц, одна строка на страницу
├── overview.md        # сквозной синтез по всем 64 видео + открытые вопросы
└── pages/<slug>.md    # Sources (по одной на видео), Concepts (синтез темы сквозь видео), Entities
```

Читающий скил берёт `index.md` (~26k токенов), выбирает по однострочным
саммари одну-три нужные страницы и догружает только их (медиана ~800
токенов каждая). Вся вики целиком — 231 страница, ~180k токенов, поэтому
она и разбита: типичный ответ обходится в пределах пары тысяч токенов
вместо всей вики.

Все 64 видео канала обработаны по состоянию на 2026-08-15. Пайплайн
`tokovinin-video-flow` (Hermes + cron), который раньше пополнял `kb/`, для
этого формата не используется и сейчас отключён — считать вики «всем, что
обработано на момент последнего ингеста», а не «живым зеркалом канала».

`index.md` руками не правится, он генерируется из фронтматтера страниц:

```bash
python3 bin/generate-index.py
```

Каждая страница Concepts синтезирует тему сквозь несколько видео с
footnote-цитатами на конкретный таймкод; Source-страницы явно помечают,
когда видео — по большей части перемонтаж/ремикс уже обработанного
материала, а не новый контент. Канал в основном в формате реакции, поэтому
позиция Токовинина и позиция разбираемого ролика в конспектах разведены
явно. Скил цитирует с прямыми ссылками на момент в видео
(`youtu.be/<id>?t=514`).

`transcripts/` в `.gitignore`: это ~50 МБ сырых автосубтитров, локальный
аудит-след, ничему в репозитории они не нужны.

## Оговорки

- База — производная от публичных автосубтитров YouTube: синтез своими
  словами с короткими вербатимными цитатами и ссылкой на конкретный таймкод,
  не транскрипт и не копия видео.
- Проект неофициальный, к Мише Токовинину и его каналу отношения не имеет.
- Вики зафиксирована на 64 видео по состоянию на 2026-08-15 — не живое
  зеркало канала, а снимок на момент последнего ингеста.
